Recursion and Function Pointers

Part A - Basic Questions

1. What are the base case and recursive case for your factorial?

The base case is when n is 0 or 1, and the function returns 1. The recursive case is n multiplied by factorial(n - 1). Each recursive call decreases n by 1, moving toward the base case.

2. What goes wrong if you omit the base case?

Without a base case, the function would keep calling itself without stopping. Eventually the program would run out of stack memory, causing a stack overflow or program crash.

3. When might a loop be better fit than recursion for summing an order?

A loop may be better when simply summing a list because it is usually simpler and uses less stack memory. Recursion is useful for learning recursive problem solving, but an iterative loop can be more practical for a straightforward list sum.

Hand Traces

factorial(4):

factorial(4)
= 4 * factorial(3)
= 4 * 3 * factorial(2)
= 4 * 3 * 2 * factorial(1)
= 4 * 3 * 2 * 1
= 24

As the stack unwinds:
factorial(1) returns 1
factorial(2) returns 2
factorial(3) returns 6
factorial(4) returns 24

fib(4):

fib(4)
= fib(3) + fib(2)

fib(3)
= fib(2) + fib(1)
= 1 + 1
= 2

fib(2)
= fib(1) + fib(0)
= 1 + 0
= 1

Therefore:
fib(4) = 2 + 1 = 3

This version works because each recursive call reduces n toward the base cases n <= 1. The function combines the results of fib(n - 1) and fib(n - 2), which follows the Fibonacci definition.

Part B - Function Pointers

1. What does a function pointer store?

A function pointer stores the address of a function. It allows a program to call that function through the pointer.

2. How can apply_op stay unchanged while the cafe changes which pricing rule runs?

apply_op receives a function pointer as an argument. The caller can pass different functions, such as add_cents or percent_off_amount, without changing the code inside apply_op.

3. Name one real-world callback example that you can think of or learn about.

A graphical user interface can use callbacks for events such as clicking a button. When the event happens, the program calls the function associated with that event.

Part C - Git

1. Why is a hand trace useful before you chase a recursive bug in the debugger?

A hand trace shows each recursive call and return in order. It can reveal whether the base case is correct and whether each recursive call moves toward it before using a debugger.

2. Which commit message would you choose after fixing a missing base case, and why is that better than fix?

I would use "Fix missing factorial base case" because it clearly describes what was changed. A specific commit message is more useful than "fix" because it makes the Git history easier to understand later.
