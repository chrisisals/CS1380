
# Project Instructions

- Use C23 for all C programs.
- Compile with -Wall -Wextra -Wpedantic.
- Fix every compiler warning.
- Always check pointers for NULL before dereferencing.
- Use braces around every control-flow body.
- Keep functions small and readable.
- Use descriptive variable and function names.
- Do not use malloc unless explicitly required.
- Check union tags before reading union members.
- Test NULL pointers and invalid inputs.
